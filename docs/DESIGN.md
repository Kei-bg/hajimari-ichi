# はじまりの市 — ゲームデザイン

## 狙い

誰も設計していない経済が、分業と交換から自然に立ち上がるのを体験させる。そのために「一人では生きにくい」仕組みを重ねている。

- 土地ごとに採れる物が偏る → 交換が要る
- 道具が生産性を何倍にもし、しかも壊れる → 道具づくりと売買が続く
- 腐る物と腐らない物がある → 腐らず軽く数の少ない物が「お金」になっていく
- 運の振れと選択つきの出来事 → 毎日の判断に緊張と期待がある

## 1日の流れ

1. プレイヤーは労力4を使って行動する(採集・畑仕事・道具づくり・加工・施設づくり・遠出・休む・取引)
2. 「日を終える」で、村人が同じルールで行動 → 村人の発明・模倣 → 村人どうしの取引(人数×5回の試行、市の広場があれば×8) → 村人の普請の手伝い
3. 施設の産出(簗・塩田)、畑の生育、消費、腐敗
4. 物価・お金の通用度の更新、人の出入り、天候の出来事、吉兆の抽選、今日の出来事カードの抽選、村人からの声かけ

## 暮らしの必要

- 毎日: 食べ物2(獣の肉→魚→木の実→穀物の順に、傷みやすい物から食べる)、塩0.2、木材0.3(薪)
- 足りないと体力が減る(食べ物は不足1あたり−11、塩は0.2すべて足りないと−4、木材は0.3すべて足りないと−3。どれも不足量に比例し、手元にある分は使う)。足りれば+2、2種類以上食べると+2、首飾りがあると+1
- 体力は採集量に効く(係数 0.5 + 体力/200)。村人は体力0で村を去る

## 土地(6×4マス)

| 土地 | 地形の内訳 | 特徴 |
|---|---|---|
| 平原 | 草地14・林3・岩場2・粘土層1・川4(縦に1本) | 畑向き |
| 川辺 | 草地7・林3・岩場2・粘土層6・川6(横に1本) | 粘土層は川沿いに寄る |
| 海岸 | 草地7・林3・岩場5・粘土層3・浜6(下の1列) | 塩・真珠 |
| 森 | 林10・草地4・岩場5・鉱脈2・粘土層1・川2 | 木材・銅鉱石 |

施設を建てたマスは採集に使えない。採集量は「その地形の空きマス数」で決まる: 豊かさ = min(1.4, 0.4 + 0.12×マス数)。鉱石だけは マス数×0.5。

## 採集

| 仕事 | 地形 | 素手の基礎量 | 道具の働き |
|---|---|---|---|
| 木の実 | 林 | 1.25 | — |
| 野生の穀物 | 草地 | 0.65 | — |
| 魚 | 川・浜 | 0(道具が要る) | 漁(値がそのまま基礎量) |
| 木材 | 林 | 1.1 | 伐採(倍率) |
| 石 | 岩場・鉱脈・川 | 1.0 | 石割り(倍率) |
| 粘土 | 粘土層 | 1.0 | 粘土掘り(倍率) |
| 繊維 | 草地・川・浜 | 1.2 | 草刈り(倍率) |
| 塩 | 浜 | 0.45 | 土器があれば×1.8 |
| 銅鉱石 | 鉱脈 | 0.5 | 鉱石掘り(倍率) |

実際の量 = 基礎量 × 道具 × 豊かさ × 天候 × 吉兆(×1.5) × 体力係数 × **運**。

**運**(1回ごと): 大当たり×3(5%)/上々×1.5(17%)/外れ×0.4(8%)/通常×0.75〜1.15。お守りがあると大当たり・上々の確率が2倍。

## 道具の組み立て(先端+柄+結び)

正解を当てるのではなく、素材の性質を見て設計する方式。失敗はなく、どう組んでも何かができる。

**先端の素材**

| 素材 | 鋭さ | 硬さ | 重さ | 基本の耐久 | 性格 |
|---|---|---|---|---|---|
| 木 | 1 | 1 | 1 | 8 | 軽く柔らかい |
| 石 | 0.5 | 3 | 3 | 12 | 重く硬いが刃は付かない |
| 石刃 | 3 | 2.5 | 1.5 | 12 | 切る・刺すに向く |
| 黒曜石 | 5 | 2 | 1.5 | 7 | とびきり鋭いが脆い |
| 銅 | 3.5 | 4 | 3 | 30 | 長持ち |
| 隕鉄 | 5 | 6 | 5 | 90 | 何でも一級品 |

柄の段階 L: なし=0、短い=1(木1)、長い=2(木2)。結び: 差し込むだけ(耐久×0.45)、草で結ぶ(繊維2、×0.85)、縄で縛る(縄1、×1.25)。

**形と性能の式**(`designCalc`)

| 形 | 働き | 式 |
|---|---|---|
| 尖らせる | 漁・狩り | 0.6 + 0.3×鋭さ + 0.15×硬さ + [0, 0.2, 0.5][L](柄なしは×0.75) |
| 刃をつける | 伐採 | 1 + 0.22×鋭さ + 0.18×重さ + [−0.25, 0, 0.35][L] |
|  | 草刈り・収穫 | 1 + 0.2×鋭さ − 0.08×重さ + [0, 0.2, −0.2][L] |
| 平たくする | 粘土掘り・畑づくり | 1 + 0.15×硬さ + 0.1×重さ + [−0.1, 0.2, 0.4][L] |
| 塊のまま | 石割り | 1 + 0.12×硬さ + 0.15×重さ + [−0.1, 0.15, 0.4][L](鉱石は×1.15、狩りは×0.8) |

耐久 = 基本の耐久 × 結び(柄ありのとき) × 長い柄なら0.9 × 木の先端で平たくない形なら0.8。

- 畑づくりの値が1以上で畑と水路が作れ、2以上なら手間が労力1になる
- 収穫の値は畑の収穫量に 1 + (値−1)×0.6 で効く
- 出来の当たり外れ: 粗末(耐久×0.6、10%)/並(65%)/出来の良い(×1.5、20%)/名品(×2.5、5%)
- 名前は形と柄から自動で付く(例: 尖らせる+長い柄=槍、刃+長い柄=斧、平たい+短い柄=掘り棒)
- 一度作った型は型帳に残る。他人から買った道具の型も覚える。型は教えて対価をもらえる

| 水路 | 川か水路の隣の草地 | 労力2 | 隣の畑に水が届く |
| 簗 | 川 | 木材4・石3・縄2、労力4 | 毎日魚2 |

## 珍品と遠出

- 珍品7種: 黒曜石・貝の化石(珍しい)、琥珀・真珠(とても珍しい)、金の粒・翡翠(幻の)、隕鉄(伝説の)
- 採集のついでに低確率で出る(例: 石拾いで黒曜石4%、浜のある漁で真珠3%)。吉兆の仕事なら3倍、お守りで2倍
- 遠出: 1歩ごとに労力1。n歩目で危険に遭う確率 = 0.06 + 0.07×(n−1)(上限60%)。危険に遭うと荷の半分(珍品は半々で)を失い、体力−10〜18
- 奥ほど量が増え(×(1+0.35×(歩数−1)))、珍品の比重も上がる。旅人から型を教わる、自分の土地に泉や鉱脈が見つかる、こともある
- 宝の地図があると、3歩目より奥で必ず高位の珍品が出る

## 今日の出来事(1日22%で発生、その日のうちに選ぶ)

旅の商人(珍品・遠い国の道具を売る/村の品を相場の倍で買う)、倒れた旅人(食べ物2を分けると型か珍品のお礼)、大きな足跡(狩りは労力2、狩りの道具で有利)、嵐のあとの浜、占い師(塩1でお守り4日)、祭りの賽(勝ち38%で+賭け分、大勝ち8%で+3倍、負け54%)、地図の切れ端。

村全体の出来事: 干ばつ・嵐・実りの年・豊漁(数日続く)、熱病・獣の群れ・流れ星(その場で起こる)。

## 村人の考え方

- 毎日 `computeWant` で欲しい物の量を決める(食べ物・塩・木材の備え、狙っている道具の材料、狙っている施設の材料、お金になった物の手元在庫、余裕があれば首飾りや貴石)
- `agentVal` = 物価 × 必要度(足りない1.6、余っている0.65、食べ物が尽きそうなら×2.2)
- 労力1ごとに、採集・畑・加工・道具づくり・施設づくり・休むの中から主観価値が最大の行動を選ぶ
- 発明: 1日4%で、自分の土地と手持ちの素材で作れる型を総当たりし、最も役立つものを考え出す。模倣: 知っている人の数×2%(上限20%)で他人の型を覚える

## 交換とお金の生まれ方

- 村人どうし: 足りない物を、相手の余りと自分の余りで物々交換。合わなければ、相手が「お金」とみなす物で払う(仲立ち)
- 各村人は「自分では要らなくても受け取る」しきい値(12〜40%)を持つ
- お金の通用度(品物ごと) = 前日×0.92 + 0.08×(0.55×売れやすさ×腐りにくさ×運びやすさ + 0.9×仲立ちに使われた割合)
  - 売れやすさ = 欲しがっているのに自分では作れない人の割合
- 通用度が0.3を超えた物は、村人が手元に持っておきたがる(需要が増える)。0.5を超えると「お金として通用し始めた」と記録
- これまでの試行では、塩・真珠・金の粒・首飾りが主役になることが多い
- 物価: 不足と余りの差で毎日最大10%動く。穀物を1に固定。上限は基準値の8倍、下限は0.15倍

## 村人からの声かけ

- 毎日は来ない。村人が「困っている理由」のある物を、あなたが持っているときだけ訪ねてくる
  - 差し迫った理由(食べ物が4未満・塩が0.6未満・木材が0.9未満)なら1日50%、狙っている道具や施設の材料なら5%
  - この確率は肩書き1段ごとに×1.25、市の広場で×1.3。1日の上限は2件(市の広場があれば3件)
- 来た日は左の列のいちばん上に出る。相場の1.1倍で買ってくれる(長老から1段ごとに+0.05)
- 応じると名声+1、差し迫った理由の人なら+2

## 村の大事業

材料と人手を村じゅうで持ち寄って建てる共同の施設。一度に進められるのは1つで、あなたが呼びかけて始める。完成すると村の全員に効果がある。

| 大事業 | 必要な物 | 効果 | 話が出る条件(それまでは画面に出ない) |
|---|---|---|---|
| 井戸 | 石10・木材4・縄2・土器2・人手6 | 干ばつの害と熱病の体力減が半分 | 8日目〜 |
| 共同の倉 | 木材14・粘土10・縄3・人手8 | 食べ物の傷み×0.8、獣の群れの害が半分 | 誰かが倉を建てるか15日目〜 |
| 市の広場 | 石14・木材8・粘土6・人手8 | 村人どうしの取引の試行×1.6、旅の商人が来やすい、声かけが増える | 何かが仲立ちに使われるか20日目〜 |
| 橋 | 木材18・石8・縄5・人手10 | 遠出の危険 0.03+0.055×(n−1)(上限50%) | 25日目〜 |
| 社 | 石12・木材6・粘土6・珍品3・人手8 | 吉兆の仕事×1.5→×1.8、吉兆の珍品×3→×4、お守り4日→6日 | 10日目以降に珍品が見つかるか30日目〜 |

- **出す**: 手元の物を出す(木材は薪の分を1残す)。人手は労力1で1。珍品は安い物から1つずつ供える
- **頼む**: 村人の余りを相場の1.3倍で買い集めて回してもらう。人手は1あたり穀物2の値打ち×1.3で、最大4人を1日雇う。払いには珍品も使える(食べ物は使わず、塩と木材は1残す)。ためた財の使い道
- **村人の手伝い**: 毎日、体力60以上の村人がそれぞれ確率 [3, 6, 12, 18, 28]%(あなたの肩書きの段で決まる)で、余った材料(余りの4割、最大2)か人手0.5を出す

## 名声と肩書き

名声は村への貢献の大きさ。値打ちは品物の基準値(相場ではない)で数える。

| 行い | 名声 |
|---|---|
| 大事業に物を出す | 出した量×基準値(人手は1あたり2、珍品はその基準値) |
| 大事業に村人を頼む | 上の半分(出した人の名は村人の側に残る) |
| 大事業を完成させる | +8 |
| 声かけに応じる | +1(差し迫った理由なら+2) |
| 作り方を教える | +3 |
| 倒れた旅人に食べ物を分ける | +3 |
| 自分が考え出した型を村人が覚える | 1人につき+1 |

| 肩書き | 条件 | 得られること |
|---|---|---|
| 新参者 | — | — |
| 村の一員 | 名声10 | 声がかかりやすくなる |
| 顔役 | 名声35 | 普請に人が集まりやすい。教えたときの礼が1段ごとに+10% |
| 長老 | 名声80・大事業1つ完成 | 取引で相手が譲ってくれる(1段ごとに3%) |
| 村長 | 名声150・大事業3つ完成 | 普請に村じゅうが手を貸す |

肩書きは下がらない。一人で大事業を3つ建てると、名声はおよそ150になる。

## あゆみ帳

暮らし・道具・交換・村づくりの節目24項目。資産の額ではなく「何をしたか」「村に何が起きたか」を記録する。進み方のおおよその順に並べ、まだ達成していない最初の項目を「あなたの暮らし」に「次の目標」として出す。

はじめての道具 → はじめての取引 → 土を拓く → 実り → 暮らしの基盤 → 普請に加わる → 頼られる人 → 十日の蓄え → 発明者 → 師匠 → お金の誕生 → 村の礎 → 顔役 → 広まる型 → 名品 → 奥地へ → 目利き → 金属の時代 → 村一番の分限者 → にぎわう村 → 百日 → 珍品帳を埋める → 村を築いた人 → 村長

## 情報の出し方

序盤に情報を詰め込みすぎないよう、暮らしの基本(暮らし・土地・仕事・道具づくり・市場・年代記)から始め、条件を満たした欄から順に見せる。一度見せた欄は消さない。新しく見えるようになったときは知らせる。

| 欄 | 見え始める条件 |
|---|---|
| 村人の一覧 | 4日目、または初めて取引したとき |
| 物価 | 6日目、または初めて取引したとき(推移のグラフは8日分たまってから) |
| あゆみ帳 | 最初の項目を達成したとき。達成した項目と、まだの項目のうち次の3つだけを見せる |
| 名声と肩書き | 名声が初めて上がったとき |
| 珍品帳 | 初めて珍品を見つけたとき |
| お金の芽(と「昨日の取引」) | 何かが初めて交換の仲立ちになったとき、または15日目 |
| 村の大事業 | 最初の大事業の話が出たとき。話が出た大事業だけを並べる |
| 道具づくりの先端の素材 | 木と石は最初から。ほかは手にしたことのある素材だけ |

- 仕事の欄には、珍品が出る可能性を書かない(見つけたときの驚きを残す)
- 毎日使う量の説明は、7日目まで「あなたの暮らし」に出す
